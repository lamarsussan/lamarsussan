## 🚀 Featured Projects

### 🖥️ [Smash — Unix-like Shell](https://github.com/lamarsussan/smash-unix-shell)

A Unix-like shell written in **C++** as part of the Technion's Operating Systems course.

- ⚙️ Process creation and management, including foreground and background jobs
- 🔀 Pipes and I/O redirection
- 📡 Signal handling and POSIX system calls

**Tech:** `C++` · `Linux` · `POSIX` 

### 🧠 [Memory Allocator](https://github.com/lamarsussan/memory-allocator)

A dynamic memory allocator implemented in **C++ on Linux**, without relying on standard allocation functions.

- 🧩 Metadata-based memory block management
- ♻️ Reuse of freed blocks, splitting, and merging
- 💾 Heap allocation with `sbrk` and large allocations with `mmap`

**Tech:** `C++` · `Linux` · `Memory Management`
