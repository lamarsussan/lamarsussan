## 🚀 Featured Projects

### 🖥️ [Smash — Unix-like Shell](https://github.com/lamarsussan/smash-unix-shell)

Developed a **Unix-like command-line shell in C++**, leveraging Linux/POSIX system calls to implement process execution, job control, and inter-process communication.

**🔹 Key Features & Implementation**

- ⚙️ Implemented process creation and management, including foreground and background execution.
- 🔄 Built job control mechanisms and signal handling.
- 🔀 Implemented pipes and I/O redirection for flexible command execution.
- 🐧 Worked with low-level Linux/POSIX system calls.

**🛠️ Tech Stack:** `C++` `Linux` `POSIX` `System Programming`

---

### 🧠 [Memory Allocator](https://github.com/lamarsussan/memory-allocator)

Designed and implemented a **custom dynamic memory allocator in C++**, focusing on memory management, block allocation, and reuse.

**🔹 Key Features & Implementation**

- 🧩 Implemented a buddy allocation mechanism with block splitting and merging.
- ♻️ Developed memory block reuse and management mechanisms.
- 💾 Used low-level memory allocation techniques on Linux.
- ⚡ Explored memory allocation strategies and memory management at the system level.

**🛠️ Tech Stack:** `C++` `Linux` `Memory Management` `Buddy Allocation`
